Rotate the dial to scroll through your audio outputs — the highlighted device shows on the screen.
Push the dial (or tap the screen) to make it the Windows default output.
Nothing to set up — the list is read live from Windows. Plug/unplug a device and it shows up next time the dial loads.
Using Discord? In Discord → User Settings → Voice & Video → Output Device, choose Default. Discord can't be routed per-app, but it follows the Windows default, so it switches automatically with the dial.
